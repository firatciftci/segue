# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Don't open a public issue. Report it privately through [GitHub's vulnerability reporting](https://github.com/firatciftci/segue/security/advisories/new).

Include the Segue and macOS versions, what you found, and the steps to reproduce it. You'll get a reply within a week. Once a fix ships, we publish the advisory and credit you, unless you'd rather stay anonymous.
